## About

I'm a developer and maker from India interested in building across the boundary of software and physical systems. My work spans embedded electronics, robotics, computer vision, game development, 3D content creation, fabrication and automation.

- **Build:** ESP32 projects, sensor systems, robot control and IoT prototypes
- **Create:** Unity / Unreal experiences, Blender assets, game environments and pixel-art workflows
- **Prototype:** FDM 3D printing, motion systems and hardware experiments
- **Automate:** Python utilities, build pipelines and developer tooling
- **Explore:** C/C++, Python, Java, React and Django

🌐 **Portfolio:** [portfolio-five-sigma-s3ior1g2jz.vercel.app](https://portfolio-five-sigma-s3ior1g2jz.vercel.app) — my dedicated project and personal website
